# 无限智能科研世界（IIRW）v1.0

IIRW 的核心原则：不以复制现实 AI 为终点。居民应能质疑现有算法、提出原创架构、设计实验、训练模型，并把真实训练成果导出到现实世界。

## v1.0 已集成模块
- 世界时间、启动/暂停/逐日推进、活动日志与本地持久化。
- 12 位跨学科居民、5 个科研机构、居民专业与长期目标。
- 研究项目创建、研究假设、对照实验计划、研究笔记。
- 原创智能架构提案登记。
- 证据等级：概念、模拟、本机代码实验、真实训练、独立复现、现实验证。
- 本机模型实验室：在 Android WebView/浏览器内真实执行小型 MLP 的前向传播、反向传播与 SGD 权重更新；支持 XOR/AND/OR 数据集、评测与 JSON 权重导出。
- 世界档案 JSON 导入/导出；模型结构、权重、训练配置和预测记录可导出。
- 单 APK 离线运行，不要求部署网页服务器。

## 科学真实性边界
世界居民和社会行为当前由本地规则代理驱动，尚未接入自主通用 AI 智能体或大语言模型。模型实验室执行的是真实小型神经网络训练，但规模很小，只能验证端侧训练、评测和导出链路，不能训练 GPT 级模型，也不能据此声称产生通用智能或现实科学突破。大型训练仍需要外部算力、数据、能源和隔离执行环境。
