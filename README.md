# 无限智能科研世界（IIRW）v1.1

## 核心原则
不以复制现实 AI 为终点。居民自主提出问题、质疑任何既有算法、设计原创机制、执行实验、记录失败，并把经过验证的真实训练成果导出到现实世界。

## 完全内生运行原则
- 不接入外部 AI、LLM、云端推理 API、外部数据 API 或第三方科研服务。
- 当前自主科研引擎在本机浏览器 / Android WebView 内运行；实验数据由本机程序生成。
- 研究居民按不同研究方向轮流提出可证伪问题；执行真实 JavaScript 数值计算，比较感知机（无反向传播）、逻辑回归（梯度学习）和小型 MLP（反向传播）。
- 对线性与 XOR 两类任务分别生成训练集和未参与训练的测试集，记录训练准确率、测试准确率、耗时、随机种子、算法和研究结论。
- 保留成功和失败结果，支持导出独立科研档案 JSON。
- 原有微型 MLP 训练台继续保留，可导出网络权重和推理代码。

## 证据等级与真实性
- Level 0：概念提案。
- Level 1：规则模拟。
- Level 2：本机代码实验（自主科研引擎当前等级）。
- Level 3：真实模型训练（原有微型 MLP 训练台）。
- Level 4：独立复现。
- Level 5：现实世界验证。

Level 2 结果来自本机实际执行，但当前基准是合成二维分类任务，不能外推为通用智能或现实科学突破。居民目前是本地研究代理和实验调度规则，不是已经形成自主通用智能的实体。不得把模拟推演、合成数据实验或居民生成的结论冒充现实科研发现。

## 运行限制
- 不需要网络服务或外部账号；APK 内置研究代码。
- 世界不会在应用关闭后持续运行；连续实验仅在用户主动操作时执行。
- Android 手机算力、内存、温控和电量有限。当前实验规模刻意保持轻量。
- 真正的大规模模型训练、现实数据验证和独立复现尚未实现；完全不接外部服务意味着训练规模受本机硬件和本机数据限制。
