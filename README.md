# 无限智能科研世界（IIRW）

一个以自主探索智能本质、产生原创科研成果为目标的渐进式科研文明工程。

## 不可妥协的核心原则

IIRW 不以复制现实 AI 为终点。现实中的模型、算法和理论只是可被研究、质疑、改进或推翻的对象，不是世界发展的最终模板。

世界里的居民应逐步具备自主发现问题、提出可证伪假设、设计对照实验、编写与执行研究代码、训练和评估模型、协作争论、积累知识并提出原创智能架构的能力。真正训练成功且通过验证的模型，最终应能连同权重、架构代码、推理程序、训练配置、数据说明、评估报告和版本信息一起导出到现实世界。

## 当前版本 v0.2

- 启动、暂停世界；手动推进世界时间。
- 12 位不同专业的模拟研究者与多个研究议题。
- 自主科研流水线：质疑既有假设 → 形成可证伪假设 → 设计对照实验 → 模拟流程检查 → 证据反思 → 修订。
- 原创智能架构工坊，可登记不同于现有主流范式的研究提案。
- 实验记录、研究日志、知识与证据账本。
- 浏览器本地保存，支持 JSON 导出与导入。
- Android WebView 离线封装，构建由 GitHub Actions 执行。

## 运行

直接打开仓库中的 `index.html`，或在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch、分支 `main`、目录 `/ (root)` 后保存。

## 科学真实性边界

当前 v0.2 仍是本地规则引擎驱动的流程原型。居民尚不是真正自主的通用智能体；实验流水线当前只做流程模拟检查，没有执行研究代码、真实模型训练或现实实验。因此，架构提案、模拟记录和待检验假设都不能被称为科研发现或已训练模型。

## 后续技术路线

1. **真实研究智能体**：为居民接入可配置的语言模型/研究代理，提供独立目标、长期记忆、工具调用、同行评审与协作机制。
2. **研究执行环境**：建立隔离、可限额、可复现的代码沙箱，支持数据处理、基准测试、自动化实验和结果归档。
3. **模型训练基础设施**：接入实际训练框架与可用算力，管理数据集、训练配置、检查点、评估与资源消耗。
4. **原创架构探索**：不锁定 Transformer 或任何单一范式；允许研究非梯度学习、动态模块、事件驱动记忆、程序化推理、自组织系统等方向，并用公平基线验证。
5. **模型成果导出**：仅对真实训练且通过验证的模型提供导出，包含权重、架构/推理代码、训练配置、数据来源与许可、评估报告、版本和复现说明。
6. **证据等级制度**：严格区分概念提案、规则模拟、代码实验、真实模型训练、独立复现和现实世界验证。

## 运行边界

世界不会凭空获得无限算力、数据或实验设备。自主科研能力必须由实际接入的模型、工具、执行环境和计算资源支撑。每项成果都应保留可追溯记录，失败结果也必须保留，不能只展示成功案例。
