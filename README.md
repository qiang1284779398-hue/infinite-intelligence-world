# 无限智能科研世界（IIRW）

一个以自主科研文明为目标的渐进式原型。v0.1 是可在手机浏览器运行的本地交互原型。

## 当前功能
- 启动、暂停世界；手动推进一天。
- 12 位不同专业的模拟研究者与科研议题。
- 研究假设、项目进度、活动日志和证据账本。
- 浏览器本地保存，支持 JSON 导出与导入。
- 无需安装依赖；可直接部署 GitHub Pages。

## 运行
直接打开仓库中的 `index.html`，或在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch、分支 `main`、目录 `/ (root)` 后保存。

## 科学真实性边界
当前居民和科研活动由本地规则引擎驱动，不是真正自主的通用智能科研人员。模拟推演和待检验假设不能冒充代码实验、真实模型训练或现实科学发现。后续版本需要逐步接入真实模型、隔离代码执行环境、训练任务与可复现评估流程。
